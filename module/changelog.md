# bcw — модуль обхода

## v0.2.0 (не выпущена)

Поиск стратегий из WebUI (этап 3):

- вкладка «Поиск»: запуск, ход, «Стоп», итог, история 10 последних поисков, отчёт;
- `bcw ctl search start|status|stop|runs|report` — то же из Termux;
- найденное сохраняется пресетом, назначается сети и проверяется через обход; при провале —
  откат по `undo.json`;
- списки доменов для проверки «Общие» и «YouTube» редактируются во вкладке (`search-general`,
  `search-youtube`);
- строки `FOUND_*` в пресетах: проверка и сборка аргументов.

## v0.1.0

Первая версия: обход на nfqws2 со стратегиями по сетям, паузой дома, сторожем и откатом;
28 пресетов nfqws2-android с редактором; WebUI.
